# 🧠 CBT Diary — Telegram бот для когнитивно-поведенческой терапии

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![aiogram](https://img.shields.io/badge/aiogram-3.x-green)](https://docs.aiogram.dev/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Async-blue)](https://www.postgresql.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)

Telegram-бот для ведения дневника КПТ (когнитивно-поведенческой терапии). Помогает отслеживать эмоции, автоматические мысли и их рациональную переоценку.

---

## ✨ Возможности

### 📝 Ведение дневника
- **Пошаговый анализ ситуаций** (8 шагов)
- **Выбор эмоций** — 6 групп, 30+ подэмоций
- **Оценка интенсивности** — шкала 0-100% до и после анализа
- **Автоматические мысли и их рациональная переоценка**

### 🔄 Работа с записями
- **Черновики** — можно прервать и продолжить позже
- **Просмотр всех записей** с пагинацией
- **Удаление записей** с подтверждением

### 📊 Статистика и аналитика
- Общая статистика по записям
- Топ эмоций (с группами и подэмоциями)
- Статистика по периодам (месяцы)
- Динамика изменения интенсивности после переоценки

### 📤 Экспорт
- Выгрузка всех данных в **Excel** (.xlsx)
- Все тексты расшифровываются при экспорте

### 🔐 Безопасность
- **Шифрование** всех конфиденциальных данных (Fernet)
- **Валидация ввода** (защита от инъекций и спама)
- **Rate limiting** — защита от DoS-атак
- **CSRF-токены** для критических операций

### ⏰ Напоминания
- Ежедневные напоминания о незавершённых записях
- Настраиваемое время

## 🚀 Установка и запуск


```bash
### 1. Клонирование репозитория
git clone https://github.com/yourusername/cbt-diary-bot.git
cd cbt-diary-bot

2. Создание виртуального окружения
bash

python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate          # Windows

3. Установка зависимостей
bash

pip install -r requirements.txt

4. Настройка окружения

Скопируйте .env.example в .env и заполните:
env

# Telegram Bot (получить у @BotFather)
BOT_TOKEN=ваш_токен

# База данных PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=имя_базы
DB_USER=пользователь
DB_PASSWORD=пароль

# Безопасность (сгенерируются автоматически, можно оставить пустыми)
SECRET_KEY=
ENCRYPTION_KEY=

# Режим отладки
DEBUG=False

# Администраторы (ID через запятую)
ADMIN_IDS=123456789

5. Создание базы данных PostgreSQL
sql

CREATE DATABASE имя_базы;
CREATE USER пользователь WITH PASSWORD 'пароль';
GRANT ALL PRIVILEGES ON DATABASE имя_базы TO пользователь;

6. Запуск бота
bash

python main.py

🛠️ Технологии

    Python 3.10+

    aiogram 3.x — асинхронный фреймворк для Telegram Bot API

    SQLAlchemy 2.0 — асинхронная ORM

    PostgreSQL + asyncpg — база данных

    Cryptography — шифрование данных (Fernet)

    OpenPyXL — генерация Excel-файлов

    python-dotenv — управление переменными окружения
